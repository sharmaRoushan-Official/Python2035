Q19. Write the basic syntax of a Python decorator and explain the role of @.
Ans:-def decorator_function(func):
    def wrapper():
        func()
    return wrapper

@decorator_function
def my_function():
    print("Hello")

my_function = decorator_function(my_function)
So, @ provides a short and readable way to decorate a function.

(b)Write Python code using the requests library to send a GET request to an API.
import requests
url = "https://api.example.com/data"
response = requests.get(url)
print(response.status_code)
print(response.json())
Explain the purpose of requests.get(), response.status_code, and responsejson()

Ans:-import requests

url = "https://api.example.com/data"

response = requests.get(url)

print(response.status_code)
print(response.json())

Explanation
requests.get(url) — Sends an HTTP GET request to the specified URL. GET requests are commonly used to retrieve data from an API.

response.status_code — Returns the HTTP status code received from the server.

200 → Request was successful

404 →Worng Url

500 →  Internal Server error

response.json() — Converts the JSON response from the API into a Python object, usually a dictionary or list, so the data can be processed in Python.

For example, if the API returns:

{"name": "Alice", "age": 25}

then response.json() produces:

{"name": "Alice", "age": 25}
